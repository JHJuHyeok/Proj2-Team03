## 주요 기능
### 1. SDK 연동, 세이브 플로우

담당자: 주혁
- 데이터베이스 구축/호출/저장 
- 저장 담당 매니저(자동 저장, 원격 저장, 로컬 저장)
- 게임 구동 시 초기화 

### 2. 플레이어 정보, 재화 정보

담당자: 주혁
- 레벨, 업그레이드 정보, 보유 장비 등 플레이어 정보 전체 관리
- 플레이어 보유 재화 전체 관리

### 3. 전투 플로우

담당자: 신태환
- 스테이지 이동
- 전투 시퀀스 시각화(몬스터 스폰, 진행도, 애니메이션)
- 정보 갱신 이벤트 연결(재화, 경험치 획득)

### 4. 스킬 시스템

담당자: 조민희
- 스킬 블록 그리드 배치 및 제거
- 배치 현황 시각화, 쿨타임 표시
- 데이터 연동, 애니메이션 FX 연결

### 5. UI

담당자: 염승문
- 팝업 UI
- 씬 이동 시 비동기 전환
